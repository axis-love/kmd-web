# Ember Design System

A warm, paper-and-ember demo theme for kmd-web's designMD theming
(`designSource`). The reader extracts these tokens, maps them onto the
`--kmd-*` vocabulary, and derives the dark variant automatically — flip the
theme toggle (or `?theme=dark`) to see the inversion.
