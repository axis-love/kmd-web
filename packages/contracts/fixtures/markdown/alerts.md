# GitHub Alerts

## Note alert

> [!NOTE]
> This is a note alert with useful information.

## Tip alert

> [!TIP]
> Helpful advice for doing things better.

## Important alert

> [!IMPORTANT]
> Key information users need to be aware of.

## Warning alert

> [!WARNING]
> Urgent message that needs careful attention.

## Caution alert

> [!CAUTION]
> Negative potential consequences of an action.

## Not an alert

> This is a regular blockquote, not an alert.
>
> It should render as a plain blockquote.
